## 목적
고객군별로 지역·업종·품목 분포를 분석하고 핵심 인사이트를 AI 요약문으로 작성한다.

## 사용 시점
customer-classifier 실행 후

## 분석 항목
1. **고객군별 고객 수/비율** — 각 군의 인원수와 전체 대비 비율
2. **지역 특성** — 군별 지역 분포, 주요 지역 (고객 수 최다)
3. **업종 특성** — 군별 업종 분포, 주요 업종 (고객 수 최다)
4. **품목 특성** — 군별 품목명별 주문건수·금액·비율, 상위 품목
   - 품목명 결측 → "미상" 처리 (임의 분류 금지)
5. **AI 분석 요약** — 5문장 이내, 데이터만 근거로 작성
   - 이탈 위험률은 위험 등급 고객 수 ÷ 전체 주문 3회 이상인 이탈 분석 대상 고객 수 × 100

## 실행 방법
```bash
python .pi/skills/pattern-analyzer/scripts/analyze_patterns.py
```

## 출력
- region_analysis.csv
- industry_analysis.csv
- product_analysis.csv
- ai_summary.txt

## 제약
- 데이터에 없는 원인/사실을 생성하지 않음
- 품목명 없는 주문은 "미상"으로 처리
- 모든 결과는 한국어
