# 고객분석 영역
# 실제 실행 코드: services/customer/



## 목적
고객 분류 기준(신규→이탈위험→재이용 우선순위)에 따라 각 고객의 최종 고객군을 결정한다.

## 사용 시점
churn-risk-scorer 실행 후

## 분류 우선순위 (반드시 이 순서)
1. **신규 고객**: 최초 주문일 >= 조회 시작일 → 다른 분류 스킵
2. **이탈 위험 고객**: 주문 3회 이상 + 이탈 위험 등급이 주의/위험 → 재이용 분류 스킵
3. **재이용 고객**: 조회 기간 이전 주문 + 조회 기간 내 재주문
4. **일반 고객**: 위 3가지에 모두 해당하지 않음

## 실행 방법
```bash
python .pi/skills/customer-classifier/scripts/classify.py
```

## 출력
- customer_groups.csv (customer_id, 고객군, 전체 주문 횟수, 최근 주문일, 평균 이용 주기, 최종 주문 후 경과일, 평균 주기 대비 경과 비율, 이탈 분석 대상 여부, 이탈 위험 등급, 판단 근거)
- churn_risk_customers.csv (이탈위험고객만 추출)

## 제약
- 한 고객에게 하나의 고객군만 부여
- 분류 기준을 임의로 변경하지 않음
- 이탈 위험 고객군에는 주의·위험 등급 고객만 포함
- 단골 고객이라는 별도 고객군을 추가하지 않음
- 주문 1회는 판정 제외, 주문 2회는 재이용 분류 가능하나 이탈 등급 판정 보류
- 정상/주의/위험은 주문 3회 이상인 이탈 분석 대상에게만 부여
