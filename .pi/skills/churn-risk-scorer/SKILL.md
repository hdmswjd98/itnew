## 목적
고객별 이용 지표를 바탕으로 이탈 위험 정도를 정량화하고 판정 근거를 생성한다.

## 사용 시점
metrics-calculator 실행 후, customer-classifier 실행 전

## 이탈 위험 비율 계산
```
이탈 위험 비율 = 최종 주문 후 경과일 / 평균 이용 주기
```
- 평균 이용 주기가 "계산 불가"인 경우: 이탈 위험 비율 = N/A

## 등급 판정
| 이탈 위험 비율 | 등급 |
| --- | --- |
| ≤ 1.0 | 정상 |
| 1.0 < 비율 ≤ 1.5 | 주의 |
| > 1.5 | 위험 |
| N/A (평균 이용 주기 계산 불가) | 적용 안 함 |

## 판정 근거 생성
- 정상: "평균 이용 주기({Nx일}) 이내 재방문"
- 주의: "평균 이용 주기({Nx일}) 대비 경과일({Nx일})이 1~1.5배 초과"
- 위험: "평균 이용 주기({Nx일}) 대비 경과일({Nx일})이 1.5배 초과"
- 적용 안 함: "주문 이력이 1회이거나 평균 이용 주기를 계산할 수 없음"
