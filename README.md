# 🏢 잇뉴 (ITNEW) — 통합 분석 플랫폼

제주 당일 수거·배송 서비스 '얼른'의 주문·회원 데이터를 분석해 **고객분석**,
**월간 운영 리포트**, **품목 자동분류** 3개 기능을 제공하는 Next.js 대시보드입니다.

## 🚀 로컬 실행 순서

### 0) 준비물

```bash
pip install -r requirements.txt
```

### 1) 원본 엑셀 배치

주문·회원 원본 엑셀(대외비, git에는 안 올라감)을 아래 둘 중 한 곳에 넣습니다.

- `data/raw/` (권장)
- 리포지토리 루트 (엑셀 업로드가 워크스페이스 루트에 자동 배치되는 실행 환경 대응용 fallback)

### 2) 고객분석 파이프라인 실행

```bash
python3 -m services.customer.pipeline
```

엑셀 변환 → GPS 좌표화(선택) → 검증·로드 → 병합 → 지표계산 → 이탈위험 산정 →
고객군 분류 → 패턴 분석 → 최종 검증까지 9단계를 한 번에 실행하고, `data/output/`에
결과 CSV를 생성합니다.

### 3) 품목 자동분류 실행

```bash
python3 -m services.product.classifier
```

고객분석 파이프라인과는 독립적으로 실행됩니다(순서 상관없음).

### 4) 대시보드 실행

```bash
cd web
npm install   # node_modules 없을 때만
npm run dev
# → http://localhost:3000
```

2)·3)번은 대시보드의 **"데이터 새로고침" 버튼**으로도 다시 실행할 수 있습니다
(`/api/refresh`가 두 명령을 그대로 호출합니다).

## 📊 3대 기능

| 기능 | 설명 |
|---|---|
| 고객분석 | 신규/일반/재이용/이탈위험 고객군 분류, 이탈위험 스코어링, 지역·업종·품목별 특성 분석 |
| 월간리포트 | 주문량·회원현황 자동 집계 + 이슈/조치내역/협력사요청 수기 입력 + 엑셀·PDF 결재문서 출력 |
| 품목 자동분류 | 주문 품목명을 대분류·중분류로 규칙 기반 자동 분류(LLM 미사용), 검토·수기 규칙 등록 |

**핵심 원칙**: 조회기간(공통 조회기간, 탭별 오버라이드)에 반응해야 하는 계산(고객군 분류,
지역/업종 분포)은 파이썬이 미리 계산해두지 않고 `web/src/app/api/customers/route.ts`가
매 요청마다 실시간으로 재계산합니다. 파이썬은 조회기간과 무관한 고정된 계산(개별 고객
지표, 품목 자동분류 등)만 담당합니다.

## 🤖 에이전트·스킬 하네스 (`.pi/`)

고객분석·품목분류 파이프라인은 결정론적 계산(LLM 미사용)이라, 에이전트 1개가 스킬
7개를 순서대로 호출하는 하네스로 정리돼 있습니다. 자세한 실행 순서·입출력·검증
기준은 `.pi/agents/itnew-analysis-agent/AGENT.md`와 `.pi/skills/*/SKILL.md`를
참고하세요. 월간리포트는 사용자가 계속 입력·수정·조회하는 CRUD 기능이라 이 하네스
대상에서 의도적으로 제외했습니다.

## 📁 프로젝트 구조

```
itnew/
├── .pi/
│   ├── agents/itnew-analysis-agent/   # 오케스트레이터
│   └── skills/                        # 스킬 7개 (SKILL.md)
├── services/
│   ├── customer/                      # 고객분석 파이프라인 (9단계)
│   ├── product/                       # 품목 자동분류
│   └── monthly/                       # 월간리포트 저장·엑셀·PDF 출력
├── shared/paths.py                    # 공통 데이터 경로
├── config/product_classification_rules.csv  # 품목 기업 우선 규칙
├── web/                               # Next.js 대시보드
└── data/
    ├── raw/                           # 원본 엑셀 (git 제외)
    ├── input/                         # 표준 CSV (git 제외, 파이프라인 1단계 산출물)
    ├── output/                        # 분석 결과 CSV (git 제외)
    └── sample/                        # 공개 가능한 예제 데이터
```

## 🔐 보안 주의사항

- `.env`, 원본 엑셀(`*.xlsx`), `data/raw|input|output/`은 `.gitignore`로 제외됩니다 — 팀원은
  엑셀 파일을 별도 경로로 받아 각자 로컬에 직접 넣어야 합니다.
- Kakao 지오코딩 API 키 등은 `.env`에 저장하고 절대 커밋하지 않습니다.
