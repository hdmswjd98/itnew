# 품목분석 영역
# 실제 실행 코드: services/product/



## 목적 및 범위
- 최종 병합 테이블 또는 분류 결과 데이터셋을 CSV 파일로 내보낸다.
- **포함**: 데이터셋 직렬화, CSV 인코딩 설정, 컬럼 순서 정렬, 파일 저장, 저장 확인
- **제외**: Excel 내보내기, 통계 재계산, 분류 로직 실행

## 작업 절차
1. 내보낼 분류 결과 데이터셋과 출력 파일 경로를 입력받는다.
2. 컬럼 순서를 고정 규칙(원본 주문 컬럼 → 분류 컬럼 → 메타데이터)으로 정렬한다.
3. 특수문자, 줄바꿈, 따옴표가 포함된 셀은 RFC 4180 규칙에 따라 이스케이프 처리한다.
4. 인코딩을 설정값(기본 UTF-8)으로 지정하여 CSV를 직렬화한다.
5. 지정된 경로에 CSV 파일을 저장한다.
6. 저장 성공 여부를 확인하고, 실패 시 오류 원인과 재시도 안내 메시지를 반환한다.
7. 저장 완료 후 파일 크기, 행 수, 컬럼 수를 메타데이터로 반환한다.

## 사용 규칙 및 제약 사항
- CSV 헤더는 반드시 첫 행에 포함되어야 한다.
- 셀 내부에 쉼표, 줄바꿈, 큰따옴표가 있으면 큰따옴표로 감싸야 한다.
- 인코딩 변환 실패 시 기본 UTF-8로 저장하고 경고 로그를 남긴다.
- 파일 경로가 이미 존재하는 경우 덮어쓰기 여부를 사용자에게 확인한다.
- 출력 파일은 분류 파이프라인 완료 후 즉시 생성 가능해야 한다.
- 최대 행 수가 시스템 제한을 초과하면 분할 CSV 생성을 지원해야 한다.
- 저장 후 파일 해시값을 함께 반환해 무결성을 검증할 수 있게 한다.

## 템플릿
입력:
- `dataset`: 내보낼 분류 결과 데이터셋
- `output_path`: 저장할 CSV 파일 경로
- `encoding`: 인코딩 설정(UTF-8, UTF-8-sig 등)

출력:
- `exported_file_path`: 저장된 파일 경로
- `export_stats`: {rows, columns, file_size_bytes, sha256_hash}
- `warnings`: 이스케이프/인코딩 관련 경고 목록

실행 예시:
1. 병합 테이블 200행 → CSV 직렬화
2. `classification_result.csv` 저장
3. 파일 크기 45KB, 해시값 반환
