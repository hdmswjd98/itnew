# 품목분석 영역
# 실제 실행 코드: services/product/



## 목적 및 범위
- 새로운 품목 분류 카테고리를 추가하여, 이후 AI 분류와 검증 단계에서 사용할 수 있도록 한다.
- **포함**: 카테고리 등록 입력 수신, 중복 검사, 허용 목록 갱신, 등록 이력 기록
- **제외**: 표준 품목 등록, 매핑 사전 직접 갱신

## 작업 절차
1. 신규 카테고리 등록 요청을 입력받는다.
2. 기존 허용 카테고리 목록과 중복 여부를 검사한다.
3. 중복이 발견되면 등록 불가 처리 후 사유를 반환한다.
4. 중복이 없으면 허용 목록에 새 카테고리를 추가한다.
5. 등록 시각, 등록자, 관련 표준 품목(있는 경우)을 이력에 기록한다.
6. 갱신된 허용 카테고리를 저장하고, 이후 분류 파이프라인에서 즉시 참조 가능하도록 한다.

## 사용 규칙 및 제약 사항
- 카테고리명은 계층 구조를 가질 수 있으나, 등록 시점에서는 단일 라벨로 다룬다.
- 빈 문자열 또는 공백만 있는 카테고리명은 등록하지 않는다.
- 기존 카테고리와 의미가 지나치게 유사한 경우 경고만 하고 등록은 허용한다.
- 등록된 카테고리는 즉시 분류 검증(`category-validator`)에서 사용 가능해야 한다.
- 카테고리 삭제는 허용하지 않으며, 비활성화로 처리한다.
- 등록 시 표준 품목과의 연관 관계를 함께 기록할 수 있다(선택 사항).

## 템플릿
입력:
- `new_category`: 등록할 카테고리명
- `related_standard_items`: (선택) 연관 표준 품목명[]
- `registrant`: 등록자 식별자

출력:
- `registration_result`: {status: "success"|"duplicate"|"invalid", category, dup_check_result}[]
- `updated_allowed_categories`: 갱신된 허용 카테고리 목록
- `registration_log`: {category, related_items, registrant, timestamp}[]

실행 예시:
1. “건강음료” 신규 등록 요청
2. 중복 없음 확인
3. 허용 카테고리에 추가
4. 등록 이력 저장
