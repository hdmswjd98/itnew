# 품목분석 영역
# 실제 실행 코드: services/product/



## 목적 및 범위
- `mapping-dictionary-lookup` 결과에서 매핑에 실패한 품목들을 선별해, OpenRouter AI 분류 대상이 될 목록을 만든다.
- **포함**: 미매핑 인덱스 추출, 중복 제거, 미매핑 품목 목록 생성, 신규 품목 후보 플래그 설정
- **제외**: 실제 AI 분류, 신뢰도 계산, 사용자 승인 처리

## 작업 절차
1. 매핑 조회 결과 데이터셋을 입력받는다.
2. `matched_records`에 포함되지 않은 행을 식별한다.
3. 미매핑 행만 별도 데이터셋으로 분리한다.
4. 동일 정규화 품목명이 여러 행에 존재하는 경우, 대표 1건만 미분류 목록에 포함하고 나머지는 참조 링크로 유지한다.
5. 각 항목에 “신규 품목 후보 여부” 플래그를 설정한다.
6. 미매핑 목록을 이후 `openrouter-item-classifier`로 전달할 수 있는 형식으로 변환한다.
7. 결과 데이터셋과 메타데이터(건수, 대표 예시)를 반환한다.

## 사용 규칙 및 제약 사항
- 매핑 성공 품목은 이 스킬의 출력에서 제외한다.
- 동일 정규화 품목명이라도 원본 문자열이 다른 경우, 이를 모두 미매핑으로 기록한다.
- 미매핑 목록은 분류 실패 가능성을 포함하므로, 결과 정렬은 원본 행 순서 기준으로 유지한다.
- 신규 품목 후보 플래그는 사용자 설정 또는 기본 규칙에 따라 결정한다.
- 결과가 0건인 경우에도 빈 목록을 정상 출력으로 간주한다.

## 템플릿
입력:
- `lookup_result_dataset`: 매핑 조회 결과 데이터셋
- `is_candidate_flag`: 신규 품목 후보 여부 결정 룰

출력:
- `unmapped_dataset`: {row_id, raw_name, normalized_name, is_candidate}[]
- `count`: 미매핑 건수
- `sample_items`: 대표 미매핑 품목 예시 5개

실행 예시:
1. 매핑 성공 행: 120건
2. 매핑 실패 행: 35건
3. 중복 제거 후 고유 미매핑: 28건
4. 후보 플래그 설정
5. 결과 반환
