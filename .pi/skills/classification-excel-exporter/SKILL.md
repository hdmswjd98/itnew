## 목적 및 범위
- 최종 병합 테이블 또는 분류 결과 데이터셋을 Excel 워크북으로 내보낸다.
- **포함**: 데이터셋 직렬화, 워크시트 생성, 컬럼 서식 지정, 파일 저장, 저장 확인
- **제외**: CSV 내보내기, 통계 재계산, 분류 로직 실행

## 작업 절차
1. 내보낼 분류 결과 데이터셋과 출력 파일 경로를 입력받는다.
2. 첫 번째 워크시트를 생성하고, 컬럼 순서와 헤더 이름을 설정한다.
3. 숫자형 컬럼은 천 단위 구분 서식, 비율 컬럼은 % 서식을 적용한다.
4. 검토 상태 컬럼은 조건부 서식을 적용해 승인/미검토/수정을 색상 구분한다(선택).
5. 데이터 범위를 채워 워크시트를 완성한다.
6. 지정된 경로에 .xlsx 파일을 저장한다.
7. 저장 성공 여부를 확인하고, 실패 시 오류 원인과 재시도 안내를 반환한다.
8. 저장 완료 후 파일 크기, 행 수, 컬럼 수, 워크시트 수를 메타데이터로 반환한다.

## 사용 규칙 및 제약 사항
- 출력 형식은 반드시 .xlsx여야 하며, .xls는 지원하지 않는다.
- 헤더 행은 첫 번째 행에 고정하며, 필터 기능을 활성화할 수 있다(선택).
- 데이터 내 줄바꿈은 Excel 셀 내에서 허용되도록 처리한다.
- 파일 경로가 이미 존재하는 경우 덮어쓰기 여부를 사용자에게 확인한다.
- 열이 16,000개를 초과하는 경우 분할 워크시트 생성을 고려해야 한다.
- 저장 후 파일 해시와 기본 메타데이터(행/열/시트 수)를 함께 반환한다.
- Excel 생성 라이브러리가 사용 불가능한 경우 CSV 내보내기로 폴백할 수 있다.

## 템플릿
입력:
- `dataset`: 내보낼 분류 결과 데이터셋
- `output_path`: 저장할 .xlsx 파일 경로
- `options`: {freeze_header, auto_filter, number_format, status_color}

출력:
- `exported_file_path`: 저장된 파일 경로
- `export_stats`: {rows, columns, sheets, file_size_bytes, sha256_hash}
- `warnings`: 포맷/라이브러리 관련 경고 목록

실행 예시:
1. 병합 테이블 200행 → 워크시트 생성
2. 숫자 포맷, 상태 색상 적용
3. `classification_result.xlsx` 저장
4. 파일 크기 82KB, 1시트, 메타데이터 반환
