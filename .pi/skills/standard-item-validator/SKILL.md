---

## 목적 및 범위
- AI 추천 표준 품목이 허용된 표준 품목 목록에 포함되는지 검증하여, 잘못된 추천이 이후 파이프라인으로 유입되는 것을 차단한다.
- **포함**: 허용 표준 품목 목록 로드, 추천값 존재 여부 검사, 유사도 기반 근접 검증, 검증 결과 기록
- **제외**: 신뢰도 점수 산출, 카테고리 검증, 분류 사전 갱신

## 작업 절차
1. 파싱된 AI 응답 데이터셋과 허용 표준 품목 목록 경로의 입력값을 받는다.
2. 허용 표준 품목 목록을 메모리에 로드한다.
3. 각 추천 표준 품목이 목록에 정확히 존재하는지 확인한다.
4. 정확히 일치하는 항목이 없으면, 문자열 유사도를 기준으로 근접 후보를 탐색한다.
5. 근접 후보가 임계치 이상인 경우 “유사 매칭”으로 표시하고 추천값을 보정 후보로 기록한다.
6. 허용 목록에 전혀 부합하지 않는 경우 “검증 실패”로 표시한다.
7. 검증 결과(성공/유사/실패)와 함께 수정 권장사항을 출력한다.

## 사용 규칙 및 제약 사항
- 허용 표준 품목 목록은 중앙 관리형으로 유지하며, 검증 시점에 최신 버전을 사용한다.
- 유사도 계산에는 Levenshtein 거리 또는 Jaro-Winkler 유사도 중 하나를 사용한다.
- 유사 매칭 임계치는 설정 가능하며, 기본값은 0.85로 한다.
- 검증 실패 항목은 자동 분류를 중단하고 검토 대상으로 보낸다.
- 허용 목록 자체가 비어 있는 경우 모든 항목을 실패 처리한다.
- 검증 성공 시에도 원본 AI 추천값을 덮어쓰지 않고, 상태만 기록한다.

## 템플릿
입력:
- `parsed_responses`: 파싱된 응답 데이터셋
- `allowed_standard_items_path`: 허용 표준 품목 목록 파일 경로
- `similarity_threshold`: 유사 매칭 임계치(기본 0.85)

출력:
- `validated_responses`: {row_id, raw_name, recommended_item, validation_status, matched_standard_item, similarity_score}[]
- `failed_items`: 검증 실패 품목 목록
- `suggestion_log`: 유사 매칭 추천 로그

실행 예시:
1. 추천: “코카콜라 355ml” → 허용 목록에 존재 → pass
2. 추천: “코카콜라 355밀리리터” → 유사도 0.91 → 유사 매칭
3. 추천: “콜라 제로 슈가” → 허용 목록 없음 → fail
