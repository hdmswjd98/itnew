## 목적
1~4번 스킬(prepare-customer-data, calculate-customer-metrics, classify-customer-groups,
analyze-customer-patterns)의 산출물을 모두 모아, 계산 과정에서 눈에 안 띄는 버그(중복 분류,
합계 불일치, 원본 대비 유실 등)가 없는지 마지막으로 재확인하는 안전장치다.

검증 항목: 고객별 지표 누락, 신규·재이용 분류 충돌, 이탈위험 판단 근거·필수 컬럼, 주문
횟수별 이탈 분석 기준 일치, 고객군별 인원 합계, 지역/업종/품목 수치 합계, 중복 order_id
처리, 비회원 고객 표시 등.

**참고**: 이 스킬의 결과(`validation_final.csv`)는 Next.js 대시보드가 읽지 않는다 —
콘솔에 ✅/❌로 출력되는 개발자용 QA 체크리스트다. 실패 항목이 있으면 해당 단계부터
재실행한다.

## 사용 시점
`analyze-customer-patterns` 완료 후, 파이프라인의 마지막 검증 단계

## 실행 방법
```bash
python3 -m services.customer.run_validation
```

## 출력
- `data/output/validation_final.csv`
- 콘솔에 항목별 통과/실패 및 원인 출력

## SPEC

### 목표
데이터 준비·지표계산·고객군분류·패턴분석 스킬들의 산출물을 모두 모아,
서로 다른 파일에 걸친 계산 오류(중복 분류, 합계 불일치 등)가 없는지
마지막으로 재확인한다.

### 맥락
대상: `itnew-analysis-agent`(실패 시 재실행 단계 판단)
사용 목적: 여러 스킬에 걸친 계산 버그를 배포/대시보드 노출 전에 조기 발견

### 범위
포함: 고객수 합계 일치, 고객군 중복, 이탈판단 근거·필수컬럼, 지역/업종/품목
수치 합계 일치, 중복 order_id 처리, 비회원 고객 표시 등 12개 항목
제외: 개별 스킬 자체 산출물의 내부 로직 검증 (각 스킬 자체검증이 담당)

### 제약
- 이 검증 결과는 콘솔·CSV로만 남기며 대시보드에는 노출하지 않는다(개발자용 QA)
- 실패해도 자동으로 복구하지 않는다 — 원인 단계를 사람(에이전트)이 판단해 재실행한다

### 출력 형식
파일명: `data/output/validation_final.csv`
콘솔: 항목별 통과/실패 상태와 원인

### 성공 기준
- [ ] 12개 검증 항목이 전부 "통과"
- [ ] 실패 시 실패 항목과 원인이 명시됨
