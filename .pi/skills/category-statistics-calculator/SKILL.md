## 목적 및 범위
- 최종 분류 결과에서 카테고리 단위로 주문 건수, 전체 대비 비율, 검토 상태별 분포를 계산한다.
- **포함**: 카테고리별 그룹핑, 건수 집계, 비율 산출, 검토 상태 분포 계산
- **제외**: 표준 품목별 통계, 시각화, 파일 내보내기

## 작업 절차
1. 병합 완료된 최종 분류 테이블 또는 승인된 분류 결과 집합을 입력받는다.
2. 카테고리 컬럼을 기준으로 그룹핑한다.
3. 각 그룹의 주문 건수(행 수)를 집계한다.
4. 전체 주문 건수 대비 해당 카테고리의 비율(%)을 계산한다.
5. 검토 상태별 건수도 함께 집계한다.
6. 집계 결과를 내림차순 정렬하여 통계 테이블로 반환한다.
7. 통계 계산 메타데이터를 추가한다.

## 사용 규칙 및 제약 사항
- 카테고리별 집계는 표준 품목 통계와 동일한 스냅샷 기준을 사용해야 한다.
- 미지정 카테고리(null/빈 값)는 “미지정” 그룹으로 별도 집계한다.
- 비율은 소수점 둘째 자리까지 표시하며, 총합 100%를 유지해야 한다.
- 동일 카테고리에 속한 표준 품목이 여러 개여도 하나의 카테고리로 합산한다.
- 통계 결과 테이블은 CSV/Excel 내보내기 스킬 입력 포맷에 맞춰 생성한다.
- 집계 기준 시점과 전체 건수는 요약 필드에 반드시 포함한다.

## 템플릿
입력:
- `merged_table` 또는 `approved_classification_table`
- `group_column`: 그룹핑 기준 컬럼명(카테고리)
- `status_filter`: 집계에 포함할 검증 상태 필터

출력:
- `category_stats_table`: {category, order_count, order_ratio_pct, approved_count, pending_count, modified_count}[]
- `summary`: {total_orders, total_categories, calculation_timestamp}

실행 예시:
1. “음료” → 250건, 60.1%
2. “간식” → 120건, 28.6%
3. 통계 테이블 생성
