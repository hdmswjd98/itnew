## 목적 및 범위
- 최종 분류 결과에서 표준 품목 단위로 주문 건수, 전체 대비 비율, 검토 상태별 분포를 계산한다.
- **포함**: 표준 품목별 그룹핑, 건수 집계, 비율 산출, 검토 상태 분포 계산
- **제외**: 카테고리별 통계, 시각화, 파일 내보내기

## 작업 절차
1. 병합 완료된 최종 분류 테이블 또는 승인된 분류 결과 집합을 입력받는다.
2. 표준 품목 컬럼을 기준으로 그룹핑한다.
3. 각 그룹의 주문 건수(행 수)를 집계한다.
4. 전체 주문 건수 대비 해당 품목의 비율(%)을 계산한다.
5. 검토 상태(승인/미검토/수정)별 건수도 함께 집계한다.
6. 집계 결과를 내림차순 정렬하여 통계 테이블로 반환한다.
7. 통계 계산 메타데이터(집계 기준 시점, 전체 건수, 그룹 수)를 추가한다.

## 사용 규칙 및 제약 사항
- 집계 대상은 반드시 검증 상태가 “승인”인 결과만 포함할 수 있다(설정 가능).
- 비율은 소수점 둘째 자리까지 표시하며, 총합 100%를 유지해야 한다.
- 동일 표준 품목이 여러 정규화명으로 등장해도 하나의 품목으로 합산한다.
- 미분류/보류 상태는 별도 통계 항목으로 분리한다.
- 통계 계산 시점의 데이터 스냅샷을 기준으로 하며, 실시간 갱신은 별도 스케줄러에 위임한다.
- 결과 테이블은 CSV/Excel 내보내기 스킬의 입력으로 즉시 사용 가능해야 한다.

## 템플릿
입력:
- `merged_table` 또는 `approved_classification_table`
- `group_column`: 그룹핑 기준 컬럼명(표준 품목)
- `status_filter`: 집계에 포함할 검증 상태 필터

출력:
- `item_stats_table`: {standard_item, order_count, order_ratio_pct, approved_count, pending_count, modified_count}[]
- `summary`: {total_orders, total_items, calculation_timestamp}

실행 예시:
1. “코카콜라 355ml” → 120건, 45.2%
2. “펩시 250ml” → 80건, 30.0%
3. 통계 테이블 생성
