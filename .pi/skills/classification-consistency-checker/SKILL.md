# 품목분석 영역
# 실제 실행 코드: services/product/



## 목적 및 범위
- 동일한 정규화 품목명(혹은 동일 원본 품목명)이 서로 다른 표준 품목/카테고리로 분류된 불일치를 탐지한다.
- **포함**: 동일 품목명 그룹핑, 분류 결과 비교, 불일치 탐직, 불일치 원인 태깅, 일관성 점수 산출
- **제외**: 신뢰도 계산, 분류 사전 갱신, 통계 생성

## 작업 절차
1. 검증이 완료된 품목 분류 결과 데이터셋을 입력받는다.
2. 정규화 품목명 기준으로 그룹핑한다.
3. 동일 그룹 내 표준 품목/Category가 서로 다른 경우 불일치로 표시한다.
4. 불일치 건에 대해 발생 원인 프롬프트 차이, 유사도 임계값 근접, 모델 비결정론 등을 태깅한다.
5. 불일치 품목 목록을 별도 뷰로 분리한다.
6. 전체 일관성 비율(일치 건수 / 전체 건수)을 산출한다.
7. 결과 데이터셋 + 불일치 목록 + 일관성 지표를 반환한다.

## 사용 규칙 및 제약 사항
- 동일 정규화문이라도 원본이 다르면 별도 비교쌍으로 보되, 최종 수치는 정규화 기준 그룹으로 집계한다.
- 불일치가 탐지되면 자동 확정을 보류하고 반드시 검토 대상으로 분류한다.
- 일관성 검사는 신뢰도 점수와 별개로 수행하며, 두 지표가 모두 충족돼야 자동 확정 가능하다.
- 동일 품목명 그룹 내에서 표준 품목이 2개 이상 다르면 즉시 불일치로 간주한다.
- 카테고리 불일치도 함께 검사하되, 표준 품목 불일치보다 낮은 우선순위로 태깅한다.
- 일관성 검사 로그는 사후 분석 및 모델 프롬프트 개선에 활용한다.

## 템플릿
입력:
- `scored_responses`: 신뢰도 점수 포함 분류 결과 데이터셋
- `group_key`: 그룹핑 기준(정규화문/원전 문자열)

출력:
- `consistent_responses`: 일관성 통과 결과
- `inconsistent_responses`: 불일치 결과
- `consistency_rate`: 일관성 비율(%)
- `inconsistency_log`: {normalized_name, items[], conflict_type}[]

실행 예시:
1. “콜라 355ml” 10건 → 표준 품목 9건 일치, 1건 불일치
2. 불일치 건 태깅 → 검토 대상 추가
3. 일관성 비율 97% 산출
