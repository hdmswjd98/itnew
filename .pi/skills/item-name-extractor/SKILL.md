# 품목분석 영역
# 실제 실행 코드: services/product/



## 목적 및 범위
- 검증된 주문 데이터 테이블에서 분류에 필요한 원본 품목명만 추출해 별도 데이터셋으로 만든다.
- **포함**: 품목명 컬럼 식별, 원본 값 추출, 행 단위 매핑 정보 생성, 추출 결과 저장
- **제외**: 정규화, 분류 사전 조회, AI 분류, 통계 집계

## 작업 절차
1. 검증이 완료된 데이터 테이블을 입력받는다.
2. 품목명 컬럼명을 식별한다(사용자 지정 또는 자동 탐지).
3. 해당 컬럼의 각 행 값을 원본 문자열로 추출한다.
4. 각 추출 값에 대해 행 식별자, 원본 행 번호, 데이터 오류 상태를 함께 기록한다.
5. 추출 결과를 1차원 배열로 평탄화한다.
6. 중복 행이 있는 경우 원본 행 번호를 모두 보존한다.
7. 추출 결과를 “원본 품목명 데이터셋”으로 저장하고, 이후 스킬에서 공통으로 사용할 핸들을 반환한다.

## 사용 규칙 및 제약 사항
- 품목명 컬럼이 누락되었을 경우 추출을 중단하고 스키마 검증 스킬에 위임한다.
- 빈 품목명(길이 0 또는 공백만)은 추출하되, 오류 상태로 표시한다.
- 한 행에 품목명이 여러 개 있는 복합 셀은 1개 값만 추출하며, 나머지는 경고로 기록한다.
- 추출 과정에서 원본 셀의 값은 절대 수정하지 않는다.
- 동일한 원문이라도 행이 다르면 별도 항목으로 유지한다.

## 템플릿
입력:
- `data_table`: 검증된 주문 데이터 테이블
- `item_name_column`: 품목명 컬럼명
- `order_id_column`: 주문 식별자 컬럼명

출력:
- `extracted_names`: {row_id, original_row_index, raw_name, error_flag}[]
- `dataset_id`: 추출된 데이터셋 식별자
- `error_rows`: 오류 발생 행 목록

실행 예시:
1. 데이터 테이블에서 `품목명` 컬럼 선택
2. 1행 → “코카콜라 355ml”, 2행 → “콜라355” … 추출
3. 오류 행(예: 빈 셀) 식별
4. 결과 데이터셋 저장 후 ID 반환
