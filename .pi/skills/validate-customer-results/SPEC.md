# spec.md — 전체 산출물 교차 정합성 최종 검증

## 목표
데이터 준비·지표계산·고객군분류·패턴분석 스킬들의 산출물을 모두 모아,
서로 다른 파일에 걸친 계산 오류(중복 분류, 합계 불일치 등)가 없는지
마지막으로 재확인한다.

## 맥락
대상: `itnew-analysis-agent`(실패 시 재실행 단계 판단)
사용 목적: 여러 스킬에 걸친 계산 버그를 배포/대시보드 노출 전에 조기 발견

## 범위
포함: 고객수 합계 일치, 고객군 중복, 이탈판단 근거·필수컬럼, 지역/업종/품목
수치 합계 일치, 중복 order_id 처리, 비회원 고객 표시 등 12개 항목
제외: 개별 스킬 자체 산출물의 내부 로직 검증 (각 스킬 자체검증이 담당)

## 제약
- 이 검증 결과는 콘솔·CSV로만 남기며 대시보드에는 노출하지 않는다(개발자용 QA)
- 실패해도 자동으로 복구하지 않는다 — 원인 단계를 사람(에이전트)이 판단해 재실행한다

## 출력 형식
파일명: `data/output/validation_final.csv`
콘솔: 항목별 통과/실패 상태와 원인

## 성공 기준
- [ ] 12개 검증 항목이 전부 "통과"
- [ ] 실패 시 실패 항목과 원인이 명시됨
