# 고객분석 영역
# 실제 실행 코드: services/customer/



## 목적
고객별 이용 지표를 바탕으로 이탈 위험 정도를 정량화하고 판정 근거를 생성한다.

## 사용 시점
metrics-calculator 실행 후, customer-classifier 실행 전

## 이탈 위험 비율 계산
```
이탈 위험 비율 = 최종 주문 후 경과일 / 평균 이용 주기
```
- 전체 주문 3회 이상이며 평균 이용 주기를 계산할 수 있을 때만 비율을 계산한다.
- 주문 1~2회 또는 평균 이용 주기가 계산 불가인 경우: 경과 비율 = N/A

## 등급 판정
| 이탈 위험 비율 | 등급 |
| --- | --- |
| ≤ 1.0 | 정상 |
| 1.0 < 비율 ≤ 1.5 | 주의 |
| > 1.5 | 위험 |
| 주문 1회 | 판정 제외 (분석 대상 아님) |
| 주문 2회 | 판정 보류 (분석 대상 아님) |
| 주문 3회 이상이나 평균 주기 계산 불가 | 판정 보류 (분석 대상 아님) |

## 판정 근거 생성
- 정상: "평균 이용 주기({Nx일}) 이내 재방문"
- 주의: "평균 이용 주기({Nx일}) 대비 경과일({Nx일})이 1~1.5배 초과"
- 위험: "평균 이용 주기({Nx일}) 대비 경과일({Nx일})이 1.5배 초과"
- 모든 근거에 주문 횟수, 평균 이용 주기, 최종 주문 후 경과일, 평균 주기 대비 경과 비율을 포함한다.
- 주문 1회: 단발 이용으로 이탈 위험 분석에서 제외
- 주문 2회: 주문 간격이 1개뿐이므로 판정 보류

## 실행 방법
```bash
python .pi/skills/churn-risk-scorer/scripts/score_churn.py
```

## 출력
- churn_scores.csv (customer_id, 전체 주문 횟수, 최근 주문일, 평균 이용 주기, 최종 주문 후 경과일, 평균 주기 대비 경과 비율, 이탈 분석 대상 여부, 이탈 위험 등급, 판단 근거)
