## 목적 및 범위
- 사용자가 검토 대상 품목의 분류를 승인하면, 해당 내역을 영구 저장하고 검증 상태를 “승인”으로 변경한다.
- **포함**: 승인 입력 수신, 승인 내역 저장, 검증 상태 갱신, 승인 요약 생성
- **제외**: 표준 품목/카테고리 신규 등록, 매핑 사전 수정

## 작업 절차
1. 사용자 승인 결과 목록을 입력받는다.
2. 각 승인 건에 대해 승인 시각, 승인자, 승인 전 상태를 기록한다.
3. 승인 대상 품목의 검증 상태를 “승인”으로 변경한다.
4. 승인 내역을 이력 파일에 추가 기록한다.
5. 동일 품목에 대한 이전 승인 상태가 있으면 덮어쓰고, 새 이력을 추가한다.
6. 승인 요약 통계(승인 건수, 미승인 건수, 승인률)를 반환한다.

## 사용 규칙 및 제약 사항
- 승인 전에는 반드시 검토 대상 상태여야 하며, 미검토 품목 일괄 승인도 허용한다.
- 승인 이력은 삭제 불가(append only)로 저장한다.
- 동일 품목에 대해 중복 승인 요청이 오면 최신 요청만 반영한다.
- 승인 시각은 시스템 UTC 기준으로 기록하되, 조회 시 사용자 시간대로 변환 가능하다.
- 승인 결과 저장 실패 시 해당 건은 실패 상태로 표시하고 재시도 대상으로 남긴다.
- 승인률은 승인된 건수 / 검토 대상 총 건수로 산출한다.

## 템플릿
입력:
- `review_targets`: 검토 대상 품목 데이터셋
- `approval_list`: {row_id, approved, notes}[]
- `approver_id`: 승인자 식별자

출력:
- `approval_record`: {row_id, raw_name, approved_at, approver, previous_status, new_status}[]
- `approval_summary`: {approved_count, rejected_count, approval_rate}
- `updated_dataset`: 승인 상태가 반영된 데이터셋

실행 예시:
1. 검토 대상 20건 중 18건 승인
2. 18건 상태 → “승인”
3. 2건 미승인 → 검토 유지
4. 승인률 90% 산출
