# 품목분석 영역
# 실제 실행 코드: services/product/



## 목적 및 범위
- 사용자가 업로드한 CSV 또는 Excel(.xlsx) 주문 파일을 읽어와 이후 분류에 사용할 수 있는 표준 데이터 테이블로 변환한다.
- **포함**: CSV/Excel 파일 읽기, 열 이름 정규화, 인코딩 검출, 시트 선택(Excel), 빈 행/열 정리, 읽기 전용 원본 보관
- **제외**: 스키마 검증, 품목명 추출, AI 분류, 통계 생성

## 작업 절차
1. 입력 파일 경로를 확인한다.
2. 파일 확장자(.csv 또는 .xlsx)를 판별한다.
3. CSV인 경우 인코딩을 검출하고, 열 구분자(콤마/탭/세미콜론 등)를 자동 추정한다.
4. Excel인 경우 첫 번째 시트를 기본으로 읽되, 사용자에게 시트 선택 권한을 제공한다.
5. 파일 내용을 메모리 내 데이터 테이블로 로드한다.
6. 열 이름을 Trim·제목 Case로 정규화한다.
7. 완전히 빈 행(모든 셀이 공백)과 완전히 빈 열을 제거한다.
8. 원본 파일 해시/경로와 함께, 이후 스킬에서 공통으로 사용할 수 있는 표준 데이터셋을 생성한다.
9. 로드 결과를 출력 형식(파일 경로 + 메타데이터)으로 반환한다.

## 사용 규칙 및 제약 사항
- 입력 파일은 반드시 CSV 또는 .xlsx 형식이어야 한다.
- 한 번에 최대 50MB 이하 파일만 처리한다.
- 특수 인코딩(예: EUC-KR, CP949)은 자동 검출을 시도하되 실패 시 사용자에게 인코딩 재지정을 요청한다.
- 원본 데이터는 절대 수정하지 않고, 변환된 복사본만 반환한다.
- 데이터가 이미 메모리에 로드된 경우 재읽기를 생략하고 즉시 반환한다.
- 분류 대상 컬럼이 누락되었을 경우, 추출은 진행하지 않고 스키마 검증 스킬에 위임한다.

## 템플릿
입력:
- `file_path`: 주문 파일 경로 (CSV 또는 .xlsx)
- `sheet_name`: (선택) 사용할 시트 이름/인덱스. 미지정 시 첫 번째 시트

출력:
- `data_table`: 표준 열 이름을 가진 데이터 테이블
- `schema`: {열 이름 목록, 행 수, 파일 해시, 인코딩, 시트명}
- `raw_copy_path`: 원본 데이터 복사본 저장 경로

실행 예시:
1. `file_path = "data/orders_20260803.xlsx"`
2. 확장자 확인 → `.xlsx`
3. 첫 번째 시트 로드
4. 열 이름 정규화: `주문일자`, `품목명`, `수량`, `금액` ...
5. 빈 행/열 제거
6. 해시 생성 및 데이터셋 등록
7. 결과 테이블 반환
