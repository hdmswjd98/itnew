---

## 목적 및 범위
- 사용자 검토 또는 자동 승인이 완료된 분류 결과를 원본 주문 데이터와 결합해, 분석에 사용할 수 있는 최종 병합 테이블을 만든다.
- **포함**: 원본 주문 데이터와 분류 결과 결합, 조인 키 매칭, 결측 분류 처리, 병합 테이블 생성
- **제외**: 분류 로직 재실행, 승인 처리, 통계 계산

## 작업 절차
1. 원본 주문 데이터 테이블과 확정된 분류 결과 데이터셋을 입력받는다.
2. 조인 키(원본 행 식별자 또는 주문 식별자)를 기준으로 두 데이터셋을 결합한다.
3. 분류 결과가 없는 행은 “미분류” 상태로 표시한다.
4. 분류 결과가 있지만 검증 상태가 미승인인 행은 보류 상태로 표시한다.
5. 병합 결과를 표준 스키마 컬럼 순서로 정렬한다.
6. 병합 테이블과 메타데이터(결합 행 수, 미분류 건수, 보류 건수)를 반환한다.

## 사용 규칙 및 제약 사항
- 조인 키는 반드시 유일성을 보장해야 하며, 중복 키가 있으면 경고 후 첫 번째 매칭만 사용한다.
- 원본 데이터는 절대 변경하지 않고, 결합 결과는 별도 테이블로 생성한다.
- 분류 결과가 둘 이상 존재하는 경우(최신 승인 우선) 최신 승인값을 사용한다.
- 병합 시 컬럼 순서는 원본 주문 컬럼 → 분류 컬럼 → 메타데이터 순으로 고정한다.
- 결측 분류 행이 임계치를 초과하면 병합 실패를 반환하고 원인 리포트를 생성한다.
- 병합 결과는 CSV/Excel 내보내기 스킬의 입력으로 즉시 사용 가능해야 한다.

## 템플릿
입력:
- `original_order_table`: 원본 주문 데이터
- `confirmed_classification_table`: 승인된 분류 결과
- `join_key`: 조인 키 컬럼명

출력:
- `merged_table`: 결합된 최종 테이블
- `merge_stats`: {total_rows, matched_rows, unclassified_rows, pending_rows}
- `merge_warnings`: 조인 충돌 또는 결측 경고 목록

실행 예시:
1. 원본 200행 + 분류 결과 190행
2. 조인 → 190행 매칭, 10행 미분류
3. 병합 테이블 생성
4. 메타데이터 반환
