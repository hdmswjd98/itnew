## 목적 및 범위
- 주문 데이터 테이블에 분류에 필요한 필수 컬럼이 존재하는지, 각 열의 형식이 허용 범위인지 검증한다.
- **포함**: 필수 컬럼 존재 확인, 품목명 컬럼 타입 확인, 주문 식별자 중복 검사, 날짜/숫자 형식 점검, 결측치 탐지
- **제외**: 실제 품목명 정제, AI 분류, 통계 계산

## 작업 절차
1. `order-file-loader`가 반환한 데이터 테이블을 입력받는다.
2. 필수 컬럼 목록과 실제 컬럼을 비교하여 누락 여부를 확인한다.
3. 품목명 컬럼이 문자열 타입인지 확인한다.
4. 주문 식별자 컬럼의 중복 여부를 검사한다.
5. 날짜 컬럼이 날짜 형식으로 파싱 가능한지 확인한다(선택 적용).
6. 금액/수량 컬럼이 숫자형인지 확인한다.
7. 결측치가 임계치 이상인 열을 목록화한다.
8. 검사 결과에 따라 “통과 / 수정 필요 / 실패”를 반환한다.
9. 실패 사유가 있는 경우 수정·보완 안내 메시지를 함께 제공한다.

## 사용 규칙 및 제약 사항
- 필수 컬럼은 최소 1개 이상 존재하며, 그중 품목명 컬럼은 반드시 포함되어야 한다.
- 식별자 컬럼이 중복되면 해당 행 전체를 실패 처리하지 않고, 중복 여부만 표시한다.
- 숫자 컬럼에 문자열이 포함된 경우 파싱 실패를 기록하되, 전체 파일 실패로 간주하지 않는다.
- 검증 실패 시 다음 스킬로 자동 진행하지 않고, 사용자에게 수정 요청을 한다.
- 동일 파일에 대해 재검증할 때는 이전 결과를 캐시하지 않고 처음부터 재실행한다.

## 템플릿
입력:
- `data_table`: 검증 대상 데이터 테이블
- `required_columns`: 필수 컬럼 목록
- `item_name_column`: 품목명 컬럼명
- `order_id_column`: 주문 식별자 컬럼명

출력:
- `validation_status`: "pass" | "warning" | "fail"
- `missing_columns`: 누락된 필수 컬럼 목록
- `duplicate_ids`: 중복된 주문 식별자 목록
- `type_issues`: 타입 불일치 열 목록
- `missing_values`: 결측치가 있는 열 목록
- `recommendation`: 수정 권장 사항

실행 예시:
1. `data_table` 로드
2. 필수 컬럼: `주문일자`, `품목명`, `수량`, `금액`
3. `품목명` 컬럼 존재 확인 → 통과
4. `주문 식별자` 중복 검사 → 중복 3건 발견
5. `수량` 문자열 포함 행 2건 발견
6. 결과: warning + 수정 안내
