5. 분석 결과 특이사항
--------------------------------------------------------------------------------

1. 모든 분류 성공 품목의 신뢰도가 1.00으로 나타남
   - 이는 기존 분류 사전(매핑 규칙)에 완전히 일치하는 품목만 존재했음을 의미

2. OpenRouter API 호출이 발생하지 않음
   - 60개 품목 중 53개가 기존 분류 사전에 매칭됨
   - 나머지 7개는 오류로 분류되어 AI 분류 대상에서 제외됨

3. 복합 품목명 처리
   - 슬래시(/) 구분, 복수 품목 결합, 복수 용량 존재 등의 복합 품목명은
     모두 error_flag=true로 처리되어 분류에서 제외됨

4. 영문 품목명 처리
   - "spam classic 200g" → "SPAM 클래식 200g" (첫 글자 대문자 처리)
   - "coca cola 355ml" → "코카콜라 355ml" (한국어 표준품목으로 매핑)
