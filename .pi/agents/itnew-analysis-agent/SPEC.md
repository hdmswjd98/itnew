# spec.md — 잇뉴 데이터 분석·대시보드 자동화

## 목표
잇뉴('얼른' 서비스) 주문·회원 데이터를 자동으로 분석해 고객군·이탈위험·품목
자동분류 결과를 만들고, 그 결과를 대시보드(또는 HTML 요약)로 제시한다.

## 맥락
대상: 잇뉴 운영 담당자(제주 당일 수거·배송 서비스 '얼른'의 데이터 분석 실무자)
사용 목적: 매번 수동으로 하던 고객·품목 데이터 분석과 보고를 자동화해, 이탈
고객 선제 관리와 품목별 수요 분석 등 데이터 기반 의사결정을 지원한다

## 범위
포함: 데이터 준비 → 고객 지표 계산 → 고객군·이탈위험 분류 → 지역/업종/품목
패턴 분석 → 품목 자동분류 → 전체 결과 통합 검증 → 대시보드(또는 HTML 요약)
실행까지 7개 스킬의 순차/병렬 오케스트레이션
제외: 월간 운영 리포트(사용자가 계속 입력·수정·조회하는 CRUD 기능이라 이
파이프라인형 에이전트 대상에서 의도적으로 제외 — Next.js가 직접 처리), 실제
주문 데이터 수집(외부 시스템 API 연동 등, 원본 엑셀을 받는 이후 단계부터 담당)

## 제약
- 7개 스킬 전부 LLM 판단이 들어가지 않는 결정론적 계산이다(규칙기반 품목분류
  포함) — 에이전트는 계산을 대신하지 않고 순서·재시도·설명만 담당한다
- `classify-products`는 `prepare-customer-data`만 끝나면 되므로, 나머지
  단계와 순서 상관없이 병렬 실행 가능하다
- 원본 엑셀을 `data/raw/` 또는 워크스페이스 루트에서 못 찾으면 사용자에게
  위치를 안내하고 중단한다
- 각 스킬 실행 후 입출력 파일이 정상 생성됐는지 확인하고, 실패한 단계와
  원인을 사람이 이해할 수 있게 설명한 뒤 그 단계부터 재실행한다

## 출력 형식
파일명: `data/output/*.csv`(고객·품목 분석 산출물 전부), 최종적으로 실행 중인
Next.js 대시보드 URL(`http://localhost:3000`) 또는 `dashboard_artifact.html`
(브라우저 접근이 안 되는 환경일 때)

## 성공 기준
- [ ] 7개 스킬이 설계된 순서(5번은 1번 이후 독립 병렬 가능)로 정상 실행됨
- [ ] `data/output/`에 각 스킬의 산출물 CSV가 전부 생성됨
- [ ] `validate-customer-results`의 12개 통합 검증 항목이 전부 통과함
- [ ] 최종적으로 대시보드 URL 또는 `dashboard_artifact.html`이 반환됨
- [ ] 실패 시 실패한 단계와 원인이 사용자에게 명시됨
