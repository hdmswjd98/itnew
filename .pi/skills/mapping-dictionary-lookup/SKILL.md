# 품목분석 영역
# 실제 실행 코드: services/product/



## 목적 및 범위
- 사용자가 사전 구축한 “원본 품목명 → 표준 품목” 매핑 사전에서 일치하는 항목을 찾아, 기존 분류 결과를 우선 적용한다.
- **포함**: 매핑 사전 로드, 정규화 품목명 기준 조회, 완전 일치/부분 일치 탐지, 조회 결과 캐싱
- **제외**: 신규 품목 등록, AI 분류, 신뢰도 계산, 통계 생성

## 작업 절차
1. 정규화된 품목명 데이터셋과 분류 사전 경로를 입력받는다.
2. 분류 사전 파일(JSON/CSV)을 메모리에 로드한다.
3. 각 정규화 품목명에 대해 사전 내 키를 완전 일치로 조회한다.
4. 완전 일치가 없으면 유사 키(정규화 후 동일, 공백 제거 후 동일 등)를 우선 탐색한다.
5. 조회 결과(매핑 존재 여부, 매핑된 표준 품목, 카테고리, 기존 신뢰도)를 기록한다.
6. 조회 결과를 원본 데이터셋에 결합한다.
7. 이후 스킬에서 사용할 “기존 매핑 결과”와 “미매핑 품목 목록”을 분리해 반환한다.

## 사용 규칙 및 제약 사항
- 매핑 사전은 항상 읽기 전용으로 취급하며, 조회 중에 변경하지 않는다.
- 사전 업데이트는 별도 스킬(`item-mapping-updater`)을 통해서만 수행한다.
- 동일 품목에 대해 여러 매핑이 존재하는 경우, 가장 최근 갱신된 항목을 우선한다.
- 조회에 실패한 품목은 자동으로 AI 분류 대상으로 넘기지 않고, 미매핑 집합으로 분리한다.
- 사전 파일 포맷이 깨졌거나 접근 불가한 경우 오류 상태를 반환하고 다음 단계로 진행하지 않는다.

## 템플릿
입력:
- `normalized_dataset`: 정규화 품목명 데이터셋
- `mapping_dictionary_path`: 매핑 사전 파일 경로
- `match_mode`: "exact" | "fuzzy" (기본값: exact 우선, fallback fuzzy)

출력:
- `matched_records`: {row_id, raw_name, normalized_name, standard_item, category, mapped_by}[]
- `unmatched_indices`: 매핑 실패 행 인덱스 목록
- `dictionary_version`: 사용된 사전 버전/수정일

실행 예시:
1. 정규화 품목명 “콜라 355ml” 조회
2. 사전 내 “콜라 355ml → 코카콜라 355ml, 음료” 발견
3. 매핑 결과 기록
4. 미매핑 품목은 별도 목록으로 분리
