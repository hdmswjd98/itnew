---

## 목적 및 범위
- 공백, 특수문자, 단위 표기, 대소문자, 불필요한 접미사 등을 정리하여 품목명을 분류 가능한 표준 형태로 정규화한다.
- **포함**: 공백 정규화, 특수문자 제거/통일, 단위 표준화, 대소문자 통일, 반복 문자 정리, 캐시용 정규화 버전 생성
- **제외**: 표준 품목 매핑, 카테고리 지정, AI 분류, 신뢰도 계산

## 작업 절차
1. `item-name-extractor`가 반환한 원본 품목명 데이터셋을 입력받는다.
2. 각 품목명 문자열에 대해 다음 정규화 규칙을 순차적으로 적용한다.
   - 양쪽 공백 제거
   - 내부 연속 공백을 단일 공백으로 치환
   - 비가시 특수문자/제어문자 제거
   - 단위 기호 통일(예: ml ↔ mL, kg ↔ KG)
   - 대소문자 통일(규칙에 따라 모두 소문자 또는 제목 케이스)
   - 반복된 기호/문자 정리(예: “---” → “-”)
3. 정규화 전·후 쌍을 기록한다.
4. 정규화 과정에서 원본과 동일해진 경우에도 변경 없이 유지한다.
5. 정규화 결과를 새로운 컬럼으로 추가하여 데이터셋에 결합한다.
6. 정규화 완료 데이터셋을 이후 매핑/분류 스킬에 전달한다.

## 사용 규칙 및 제약 사항
- 정규화는 비가역적 정보 손실을 최소화해야 하며, 원본 문자열은 반드시 보존한다.
- 단위 변환은 동일 물리량 범위 내에서만 허용(예: ml↔mL, kg↔KG)하고, 서로 다른 단위 간 환산(예: ml→g)은 수행하지 않는다.
- 특수문자 제거 시 품목명 의미가 손상되지 않도록 겹받침·한글 자모는 보호한다.
- 동일한 정규화 규칙을 모든 행에 일관되게 적용한다.
- 정규화 결과는 “정규화 품목명” 필드로만 출력하며, 원본 필드는 수정하지 않는다.

## 템플릿
입력:
- `extracted_dataset`: 원본 품목명 데이터셋
- `normalization_rules`: 적용할 정규화 규칙 집합

출력:
- `normalized_dataset`: 원본 + 정규화 품목명 포함 데이터셋
- `normalization_log`: {raw, normalized, rule_applied}[]

실행 예시:
1. 원본: “콜라  355ML”
2. 공백 정규화 → “콜라 355ML”
3. 단위 통일 → “콜라 355ml”
4. 대소문자 통일 → “콜라 355ml”
5. 정규화 결과 저장
