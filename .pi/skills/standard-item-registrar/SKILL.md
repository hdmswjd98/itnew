# 품목분석 영역
# 실제 실행 코드: services/product/



## 목적 및 범위
- 기존에 없던 새로운 표준 품목을 시스템에 추가하여, 이후 AI 분류 및 매핑 사전 갱신에 활용되도록 한다.
- **포함**: 표준 품목 등록 입력 수신, 중복 검사, 허용 목록 갱신, 등록 이력 기록
- **제외**: 카테고리 등록, 매핑 사전 직접 갱신

## 작업 절차
1. 신규 표준 품목 등록 요청을 입력받는다.
2. 기존 허용 표준 품목 목록과 중복 여부를 검사한다.
3. 중복이 발견되면 등록 불가 처리 후 사유를 반환한다.
4. 중복이 없으면 허용 목록에 새 품목을 추가한다.
5. 등록 시각, 등록자, 관련 원본 품목명을 이력에 기록한다.
6. 갱신된 허용 목록을 저장하고, 이후 분류 파이프라인에서 즉시 참조 가능하도록 한다.

## 사용 규칙 및 제약 사항
- 표준 품목명은 공백·특수문자 제한 규칙을 따라야 하며, 빈 문자열 등록은 불가하다.
- 동일 의미의 품목이 이미 존재하면 중복으로 간주하고 등록을 거부한다.
- 등록 시 반드시 하나 이상의 원표본 품목명 예시를 함께 받아야 한다.
- 등록된 품목은 즉시 분류 사전 갱신 파이프라인에서 사용 가능해야 한다.
- 등록 취소가 필요한 경우 삭제 이력과 사유를 반드시 남긴다.
- 표준 품목명은 카테고리와의 매핑 관계를 가질 수 있어야 하며, 등록 시점에 카테고리는 선택 사항이다.

## 템플릿
입력:
- `new_standard_item`: 등록할 표준 품목명
- `example_raw_names`: 연관 원본 품목명 예시[]
- `registrant`: 등록자 식별자
- `category`: (선택) 연관 카테고리

출력:
- `registration_result`: {status: "success"|"duplicate"|"invalid", item, dup_check_result}[]
- `updated_allowed_list`: 갱신된 허용 표준 품목 목록
- `registration_log`: {item, example_raw_names, registrant, timestamp}[]

실행 예시:
1. “코카콜라 355ml” 신규 등록 요청
2. 중복 없음 확인
3. 허용 목록에 추가
4. 등록 이력 저장
